
## -- What is it? --

A single page website that is dynamically updated instead of routing to new pages.

**Examples:**

- Google Maps
- Netflix 
- Pinterest


A single page application will have most of the information staying the same with only key features being updated at a time.



## -- Advantages --

- It will only need to initially load the HTML data
- No extra queries to a server
- Fast and responsive front-end building
- Enhanced user experiences


## -- Disadvantages --

- Puts all load on the browser
- Memoru Leakage
- JS can be disabled
- Ensuring page security


## -- Challenges with SPA --

- Search Engine Optimization (**SEO**)
- Browser history
- Analytics
- Security scanning
- Adding page loads to SPA
- Speeding up the page load
